AQM Clothing - النسخة الكاملة

هذا الملف يحتوي على الموقع كاملًا، بما في ذلك:
- index.html
- style.css
- script.js
- logo.png
- hero.jpg
- صور المنتجات والأقسام

طريقة الرفع على GitHub:
1. أنشئ Repository جديد باسم aqm.
2. فك ضغط الملف.
3. ارفع كل الملفات الموجودة داخله كما هي إلى الصفحة الرئيسية للمستودع.
4. من Settings > Pages اختر Deploy from a branch.
5. اختر branch: main و folder: /(root).
6. احفظ وانتظر حتى يظهر رابط الموقع.
